- Both reasoners matched all five pinned ROBOT oracle fixtures.
- The four-format by five-owner by two-reasoner matrix passed all 40 lanes with
  `encoded_required=true` and exact semantic identity. It covered direct,
  decoded, verified mmap, overlay, and composite owners.
- The five-case by two-reasoner regression matrix passed with pinned semantic
  parity and complete encoded-native zero-work ledgers.
- The five-case ELK worker matrix matched in-process results after verified
  wire/mmap reopening and reported zero OWL parses.
- The complete OAEI suite passed 242 tests on CPython 3.14 against installed
  `0.2.x` dependencies (portable core plus native reasoners). Ruff and strict
  mypy passed. The exact native artifacts in the table were exercised by the
  four matrices above on CPython 3.12.
- A separate dependency-free environment passed 238 tests with 32 optional
  native/RDF tests skipped. The base wheel imported without loading
  `pyowl_core`, and all three CLI help surfaces passed.

The local matrix is release evidence for these artifact payloads, not a claim
